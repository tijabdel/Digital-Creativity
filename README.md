# StudentHouse.ma 🏠
La plateforme de logement étudiant intelligente au Maroc.

## 📋 À propos
Ce projet a été réalisé dans le cadre de notre formation académique. Il utilise **Django**, **Bootstrap** et **Leaflet** pour offrir une expérience de recherche de logement fluide et sécurisée.

## 🚀 Installation pour le Jury / Public
1.  Cloner le repo : \git clone [URL_DU_REPO]\
2.  Installer les requis : \pip install -r requirements.txt\
3.  Lancer les migrations : \python manage.py migrate\
4.  Injecter les données de démo : \python seed.py\
5.  Lancer le serveur : \python manage.py runserver\
